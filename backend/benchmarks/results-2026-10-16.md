## Findings and limits

- Both Python documentation languages included all expected tutorial/reference
  pages. All selected URLs stayed under their respective `/3/` and `/fr/3/`
  prefixes. The earlier two-site smoke run also caught archive downloads consuming
  attempts; those archive extensions were filtered before this run.
- Paul Graham's root/index duplicate collapsed to one URL. The essay index was
  still missing despite only 12 attempts, so page budget alone does not explain
  that site's gap. Books to Scrape also removed one duplicate, but its expected
  product page was absent while navigation/category pages consumed the budget.
- Quotes to Scrape retained content but rejected author-page redirects outside
  the allowed origin. This batch does not relax origin/HTTPS protections.
- GOV.UK included the expected benefits link but its large sitemap children
  exceeded the existing 2 MB response limit. The partial result preserves those
  warnings; increasing limits needs a separate resource-budget decision.
- NASA missed the expected missions overview; the selected set was dominated by
  aeronautics pages discovered through its sitemap. Discovery prioritization
  remains a candidate for the next batch.
- The JavaScript app passed mechanical checks with 329 extracted characters and
  its homepage link. Its generated file still contains only a basic product
  overview. This is evidence of the content-length gate's limits, not proof of
  JavaScript support. No browser rendering was added.
